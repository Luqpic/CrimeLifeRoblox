# Model Assignment

Which Claude model does which CrimeLife Tycoon work. The developer asked on 2026-11-14 to "assign the appropriate models used for this. (Opus, Fable and Sonnet)". The split below is Claude's proposal; the developer has not changed it.

| Model | Work |
|---|---|
| **Fable** | Game design and the selling point, architecture of the merge, economy and retention design, hard bugs, the final review of every batch. |
| **Opus** | Building each system batch in Studio to an approved plan: tycoon core, base raiding, merge steps, the third-person toggle. |
| **Sonnet** | Web research, bulk surveys of the places (part counts, script audits, duplicate finding), mechanical cleanup, vault upkeep. |

## How to apply

- A design or plan is written by Fable and approved by the developer before Opus builds from it.
- Sonnet's findings are reports, not proof: check a count or a claim before it goes into a decision.
- Two builders never write to the same Studio place at once.
